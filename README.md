# mmbeam-thesis
# 毫米波通信智能波束-定位联合优化 AI 系统

基于深度学习训练的 5G 毫米波通信用户定位与最优波束选择联合优化系统（本科毕业设计）

## 主要成果

- 波束 Top-3 命中率 **100%**
- 导频开销降低 **87.5%**
- 定位 RMSE 12.56m
- 模型参数量 0.09M，推理延迟 <1ms

## 技术栈

PyTorch / Sionna 射线追踪 / CUDA / DeepSense 6G 格式

## 项目亮点

1. **AI 模型训练**：PyTorch/CUDA 训练共享编码器双任务神经网络，实现用户定位与最优波束选择的联合优化
2. **数据工程**：基于 Sionna 射线追踪生成 5 万条 28GHz 信道数据集，网格复用加速将计算从 10 小时优化至 2 小时
3. **瓶颈分析**：通过 8 组对照实验定位"波束覆盖范围决定定位分辨率"的物理瓶颈，完成 MLP/CNN 多架构对比验证
